# Project IF — MVP 개발 체크리스트

> 목표: 기존 백엔드 실무 경력을 보완할 수 있도록 API 설계, 상태 일관성, 테스트, 배포 및 운영을 검증 가능한 코드로 완성한다.
> 범위: 고정 JSON 시나리오 1개를 사용하는 게스트 플레이 서비스. 사건 묶음 랜덤화, 나비효과, 다중 시나리오, 회원가입 및 광고는 MVP 이후로 미룬다.
