검증 명령어:

```sh
npm ci
npm test
npm run build
npm run lint
```

Mock 기반 단위 및 컴포넌트 테스트와 실제 브라우저 수동 통합 검증을 병행했다.

컴포넌트 테스트에서 연속 클릭 시 행동 실행 함수가 한 번만 호출되는 것을 검증했다. 실제 브라우저의 중복 POST 요청 횟수에 대한 별도 자동 E2E 검증은 포함하지 않는다.

## 4. 설계 원칙

- 게임 상태 및 결과의 최종 결정 권한은 서버에 있다.
- 프론트엔드는 공개 PlayViewV2를 기반으로 화면을 구성한다.
- 행동 및 포기 요청은 expectedVersion을 사용한다.
- 충돌 및 불명확한 요청 결과에 대해 서버 상태를 우선 재조회한다.
- 이전 행동을 최신 버전으로 자동 재전송하지 않는다.
- HttpOnly 게스트 쿠키는 JavaScript에서 직접 관리하지 않는다.
- 개발 환경에서는 Vite 프록시를 사용하여 동일 출처 API 요청을 유지한다.
- 시각적 표현과 게임 진행 정책을 분리한다.

## 5. 알려진 콘텐츠 개선 사항

office_fire_01의 OFFICE_REFUGE 장면에서 REDUCE_SMOKE 행동이 게임 시작 후 15분부터 허용되는 문제를 수동 플레이 중 발견했다.

- 사무실 피신 직후 예방적 문틈 차단 행동 허용 검토
- 119 신고 결과의 상황별 대응 안내 보완
- 예방 행동 가능 조건과 연기 유입 시점 분리
- 관련 행동 결과 및 구조 분기 재검증
